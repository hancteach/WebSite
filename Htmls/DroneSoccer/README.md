# 製作與測試截圖紀錄

雙擊 `index.html` 用瀏覽器開啟（不需要網路，也不需要啟動主機）。

- 收錄第 5 階段到 v0.10.0 的 83 張代表性截圖，依版本分章：系統功能總覽、v0.5.0 大屏觀賽、v0.6.0 打包與手冊、v0.7.0 Blender 球機與烘焙場館、v0.8.0 觀眾與 GTAO、v0.9.0 攻擊手與隊色、v0.10.0 外觀主題。
- 每張都有說明，並標示「製作過程」（藍）或「測試驗證」（紅），可篩選；點圖放大、左右鍵切換。
- 截圖都是在雲端用無頭瀏覽器（無顯示卡、軟體算圖）實際操作時拍下的。
- `img/`：放大檢視用（最寬 1600 px）；`thumb/`：縮圖。
